# 新托福 AI 写作训练与评分平台｜求职作品集 V2

本项目是独立公开的 **AI 应用产品经理作品集 / 安全静态 Mock 交互演示**，供招聘经理在几分钟内了解个人项目的产品定位、用户问题、关键产品决策、模拟交互、工程验收证据和能力边界。

## 访问路线

- **作品集总览**：为何做、服务何种用户问题、个人角色和当前阶段。
- **5分钟体验导览**：产品定位 → 学生模拟练习 → 人工校准 → 关键取舍 → 验证证据。
- **产品决策**：异步评分、Human-in-the-loop 校准、模型成本治理。
- **验证证据**：以历史已验收提交为基线，区分进行中的安全治理和不具备的商业化证据。
- **能力边界**：静态页面、真实项目能力、待验证能力三者明确分开。

## 真实性说明

- 账号粉丝1000+、累计相关咨询100+是**内容账户的需求洞察来源**，不是本平台的真实使用人数。
- 页面中学习成绩、推荐匹配度、分数变化、人工评分、虚构作文、费用/Token、操作进度均为**预设演示数据**。
- 无论用户输入什么，评分报告均是预置Mock，不实时评估用户作文，不代表官方TOEFL评分。
- 已验收的历史CI基线为主项目 B3-B1（Commit 21debd09152efbbf379adf83c4c426302cb453ea / Run 38339162342）；不证明当前尚未验收的并发治理改动通过。
- 尚未宣称正式上线、真实模型评分一致性通过、付费转化或真实用户留存。

## 安全边界

- 不包含任何真实 API Key、生产数据库、真实用户作文、私有代码或系统 Prompt。
- 不调用外部模型，不上传表单和作文，不产生 Token 费用，不追踪用户，不下载远程资源。
- 浏览器的演示状态只保存于本机 localStorage；作文编辑器内容不上传也不持久保存，可一键重置。
- 本演示不实现后端账号或真实权限隔离；双盲与仲裁只是流程模拟。
- 主 SaaS 项目独立于本公开仓库，不受本仓库修改或部署影响。
